Español 2 · El pretérito

Regular preterite plus the two spelling-change groups: -car / -gar / -zar and i → y. Plan: notes 5 min, then type drill alone for 10 min, then write 5 sentences.

1. Regular preterite endings

-ar (hablar)-er / -ir (comer, vivir)
yohablécomí
túhablastecomiste
él / ella / Ud.hablócomió
nosotroshablamoscomimos
vosotroshablasteiscomisteis
ellos / ellas / Uds.hablaroncomieron

The accents on yo (é / í) and él (ó / ió) matter: hablo = I speak (now), but habló = he spoke.

2. -car / -gar / -zar: only the yo form changes

Why? To keep the same sound before é.
  • -car: c → qu: buscar → busqué, tocar → toqué, sacar → saqué, practicar → practiqué, explicar → expliqué
  • -gar: g → gu: llegar → llegué, jugar → jugué, pagar → pagué, apagar → apagué
  • -zar: z → c: empezar → empecé, almorzar → almorcé, comenzar → comencé, organizar → organicé
Every other form is regular: tú buscaste, él llegó, nosotros empezamos.

3. i → y: only él / ellos change

For -er/-ir verbs whose stem ends in a vowel (le-er, cre-er, o-ír, ca-er, constru-ir), the i between two vowels becomes y.
leeroírconstruir
yoleíoíconstruí
túleísteoísteconstruiste
él / ellaleyóoyóconstruyó
nosotrosleímosoímosconstruimos
ellos / ellasleyeronoyeronconstruyeron
Also note: leer, creer, oír and caer put an accent on the í in tú / nosotros (leíste, leímos). -uir verbs like construir don't.

6. Write it (5 min)

Write 5 sentences about what you did yesterday (ayer). Use at least 3 of these: llegar, jugar, empezar, buscar, practicar, almorzar, leer, oír.
Example + checklist

Ayer llegué a la escuela a las siete y media. Almorcé con mis amigas. Después practiqué tenis y jugué un partido. Por la noche leí un libro y mi hermano oyó música.

Check: yo forms end in -é/-í with the spelling change (llegué, almorcé, practiqué, jugué)? Él/ella of leer/oír uses y (leyó, oyó)? Accents in place?
